Hidden Gem 1.0.3
===============

9Router / OpenAI-compatible APIs:
- Select 9Router in Settings.
- Keep the router server running. Default local API: http://localhost:20128/v1
- Save the dashboard API key. It is stored separately from the Gemini key.
- Refresh models or paste the exact model ID. Save settings, then test the connection.
- Other OpenAI-compatible services work with their own base URL and API key.
- Screen questions require a vision-capable route/model.
- Voice requires an STT model in 9Router; enter its exact ID in Settings.
- With no STT model configured, live monitoring uses the selected window only.
- Router/provider quotas and pricing still apply. Model listing does not mean free access.

Latency:
- Removed the artificial 10-second chat delay.
- Total request timeout: 45 seconds by default, configurable from 5 to 120 seconds.
- Streaming stops if no answer text arrives within 20 seconds (or a shorter configured timeout).
- Deadline includes discovery, connection, headers, and body reads.
- Chat shows elapsed time. Diagnostics record time to first text and total duration.
- A timeout means the provider did not respond in time; it does not prove the API key is invalid.

Verification:
Regression tests cover router chat, model listing, streaming, vision payloads, STT uploads,
provider switching, stalled headers, silent streams, and cancellation.
Live router/upstream access remains dependent on the user's running server and connected providers.
