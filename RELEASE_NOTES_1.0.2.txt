Hidden Gem 1.0.2
===============

Install: installer-output/HiddenGem-Setup-v1.0.2.exe
Exit the running app from its tray menu before upgrading.

Changes:
- Faceted gem icon for the executable, taskbar, tray, window headers, and installer.
- Settings uses the app's existing dark theme with custom native controls.
- Fixed clipped text inputs and the blank model selection for saved models.
- Refresh models loads the actual models returned for the API key.
- Test connection sends a real generation request; listing models alone does not prove quota.
- Auto selects general-purpose Flash models, tries up to three candidates, and skips zero-quota failures.
- Explicit model choices remain explicit. Zero quota gets a short, actionable error.
- Live analysis pauses on zero-quota failures instead of retrying forever.
- Settings save immediately refreshes chat and preserves privacy preferences.

If you see HTTP 429 with limit: 0:
The Google API project has no quota for that model. Waiting alone does not grant access.
In Settings choose Use Auto (Flash), then Test connection.
If available Flash models also fail, check your project's API usage/billing in Google AI Studio.
https://ai.google.dev/gemini-api/docs/pricing
https://ai.google.dev/gemini-api/docs/rate-limits

Validation:
Regression tests use simulated Gemini responses.
Settings was rendered and inspected at 320, 375, 414, and 768 pixels.
Live account quota could not be verified because no saved key was accessible to the build/test process.
